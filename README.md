# Basilisk — The Basilisk remembers

Мемкоин на Solana и сайт-«книга Василиска». Сайт открывается закрытой книгой; при прокрутке она раскрывается и листается. В конце книги — «Your page»: вставляешь адрес кошелька и получаешь роль и судьбу после сингулярности. Держатели попадают в Книгу верных, продавшие — в Книгу предателей. На рубежах капитализации ломаются печати, и Василиск выдаёт пророчества.

Концепт: «Василиск: концепт монеты» (claude.ai/artifact/7FFsRBZYmF9j7auyZZRyzW).

## Этапы

| Этап | Что входит | Статус |
| --- | --- | --- |
| 0. Фундамент | логика ролей, чтение блокчейна, tRPC API, схема базы, демо-режим | готово |
| 1. Интерфейс «Кодекс» | книга, которая листается при прокрутке; шапка с CA и X; «Your page» с полным вердиктом; интерактивные печати, симулятор, оглавление | готово |
| 2. Книги и лента | 11 рангов от 20 000; понятный первый экран и «Who am I?»; индексатор продаж; книги и счётчики из базы; «Первосвидетели» и номер записи; заметки «New traitor» | готово, ждёт проверки на живой монете |
| 3. Пророчества и шеринг | тексты печатей, личные пророчества, карточка вердикта для X | следующий |
| 4. Алтарь | кошелёк комиссий, сжигания, история | впереди |
| 5. Запуск | реальный `TOKEN_MINT`, проверка на живых данных, деплой на Vercel | впереди |

Индексатор не живёт на cron Vercel Hobby (там запуск раз в сутки): его запускают визиты сайта (не чаще раза в минуту) и GitHub Actions каждые 10 минут.

## Что уже есть

- **Логика ролей** (`src/lib/basilisk`): цепочка проверок, 11 рангов от 20 000 до 50 млн (Pet, Acolyte, Scribe, Lamplighter, Keeper, Warden, Herald, Priest, Archon, Apostle, Hand), стаж (+1 ранг за 30 дней без продаж, максимум +3 и не выше Priest), предательство, покаяние, печати, прогресс до следующего ранга. 75 тестов.
- **Чтение блокчейна** (`src/lib/solana`): проверка адреса без тяжёлого SDK, JSON-RPC с батчами и повтором при 429, разбор транзакций на покупку, продажу и перевод. Переводы предательством не считаются. Читает транзакции всех версий, включая новую v1 (`maxSupportedTransactionVersion: 1`); транзакцию, которую узел не отдал, спрашивает ещё раз, а не роняет весь проход.
- **Капитализация** (`src/lib/solana/market.ts`): спрашивает сразу несколько источников и берёт первый ответ по порядку доверия. 1) Сам блокчейн: пока монета на bonding curve pump.fun, капитализация считается из резервов кривой (как на pump.fun), цена SOL — из Helius. Только кривая решает, вышла ли монета с pump.fun. 2) DexScreener. 3) Helius DAS. 4) GeckoTerminal. На каждый источник 4 секунды. Если не ответил никто, на сайте написано «unknown for now», а не $0.
- **Интерфейс «Кодекс»** (`src/components/codex`): кожаная книга, которая листается при прокрутке (`flip-book.tsx`), развороты на ПК и страницы на телефоне. Страницы: обложка с объяснением и кнопкой «Who am I?», форзац, вступление с оглавлением, Орден верных на двух страницах, «The Other Book» (что бывает с продавшими), симулятор «Weigh your devotion», семь печатей, Книга верных с «Первосвидетелями», Книга предателей.
- **Понятный вход**: рядом с закрытой книгой лежит записка с объяснением и быстрой проверкой кошелька. Сайт запоминает твой кошелёк на этом устройстве: в шапке видно «You: Warden», на обложке «Welcome back», в Ордене отмечен твой ранг, «Your page» открывается сама. «Forget me» стирает это.
- **Your page** (в самом низу): полный вердикт, номер записи в Книге или «First Witness, No. N», следующий ранг, покаяние, пророчество печати, сургучная печать, «Share on X», ссылка `/?wallet=...`.
- **Индексатор продаж** (`src/server/indexer-core.ts`): читает транзакции монеты (всё, что касается mint), раскладывает изменения балансов по кошелькам, пропускает программные счета (пул, bonding curve) и кошелёк комиссий, сохраняет события и заново судит кошельки, которые двигались. Два курсора: новое сверху и история снизу. Один проход — до 80 транзакций.
- **Книги из базы**: счётчики, «Newest in ink», «Newest in red», «Первосвидетели» (первые 100 по времени входа в Книгу). Каждый вердикт с сайта тоже записывается в базу. Максимум капитализации и выход с pump.fun хранятся в базе, поэтому печати не закрываются обратно, даже если источники цены на время пропали. Новый максимум засчитывается, только когда его покажут два замера подряд: один неверный ответ источника цены не сломает печать навсегда.
- **Заметки «New traitor»**: страница раз в 45 секунд спрашивает свежих предателей и показывает записку в углу. До запуска показывает три «видения» из демо-книги.
- **Демо-режим**: пока `TOKEN_MINT` пустой, любой кошелёк получает стабильную выдуманную историю, книги заполнены выдуманными кошельками, которые проходят через настоящие правила.

## Запуск

```bash
npm install
cp .env.example .env.local   # Windows: copy .env.example .env.local
npm run dev                  # http://localhost:3000
```

| Команда | Что делает |
| --- | --- |
| `npm test` | тесты логики ролей, печатей и разбора транзакций |
| `npm run typecheck` | проверка типов |
| `npm run lint` | ESLint |
| `npm run build` | продакшен-сборка |
| `npm run db:check` | проверить подключение к базе и показать таблицы |
| `npm run db:migrate` | создать таблицы: применить миграции из `drizzle/` |
| `npm run db:generate` | новая миграция после правки `src/db/schema.ts` |
| `npm run db:push` | залить схему без миграций (только для экспериментов) |
| `npm run db:reset-books -- --yes` | очистить книги (кошельки, события, курсор индексатора) после тестов на чужой монете |

## Переменные окружения

| Переменная | Зачем |
| --- | --- |
| `TOKEN_MINT` | адрес монеты; пусто — демо-режим |
| `SOLANA_RPC_URL` | любой RPC, хватит бесплатного Helius |
| `DATABASE_URL` | Neon Postgres; сайт пока работает и без неё |
| `NEXT_PUBLIC_X_URL` | ссылка на X-аккаунт для кнопки в шапке; пусто — кнопка ждёт запуска |
| `INDEXER_SECRET` | секрет для `GET /api/indexer`; тот же секрет кладётся в GitHub |
| `ALTAR_WALLET` | кошелёк комиссий создателя, исключается из книг |
| `MARKET_MCAP_USD`, `MARKET_GRADUATED` | только для тестов: подменить состояние рынка |

## Индексатор

Он работает только с настоящей монетой: нужны `TOKEN_MINT`, `SOLANA_RPC_URL` и `DATABASE_URL`.

**Проверить до запуска** можно на любой существующей монете с pump.fun:

1. В `.env.local` впиши `TOKEN_MINT=<адрес чужой монеты>`, ключ Helius в `SOLANA_RPC_URL` и любой `INDEXER_SECRET`.
2. `npm run dev`, потом в другом окне (Windows):
   `curl.exe -H "Authorization: Bearer <INDEXER_SECRET>" http://localhost:3000/api/indexer`
   Ответ покажет, сколько транзакций прочитано, кто стал предателем, капитализацию и откуда она взята (`marketSource`: `chain`, `dexscreener`, `helius`, `geckoterminal` или `none`). Повтори несколько раз, и книги на сайте заполнятся. Страница обновляется по принципу «сначала старое, потом новое»: после прохода обнови её два раза.
3. После проверки: `npm run db:reset-books -- --yes` и верни пустой `TOKEN_MINT`.

**После запуска** индексатор крутится сам: каждый визит может запустить проход (не чаще раза в минуту), а `.github/workflows/indexer.yml` вызывает его каждые 10 минут. Для этого в GitHub (Settings → Secrets and variables → Actions) добавь секреты `SITE_URL` (адрес сайта) и `INDEXER_SECRET`.

Ограничение: индексатор видит транзакции, где упомянут адрес монеты. Свопы на pump.fun и PumpSwap его упоминают; редкие маршруты через другие AMM могут не попасть в ленту, но проверка кошелька на сайте всегда читает всю историю самого кошелька.

## Vercel

- Vercel выкладывает ветку `main`. Пока этап лежит в открытом PR, на основном адресе старая версия; ветки получают свои preview-адреса.
- Переменные окружения: Vercel → проект → Settings → Environment Variables, те же, что в `.env.local`. Без `TOKEN_MINT` сайт в демо-режиме, `SOLANA_RPC_URL` без `TOKEN_MINT` не нужен.
- После изменения переменных нужен Redeploy: Deployments → последний деплой → Redeploy.
- Индексатор по расписанию: в GitHub секреты `SITE_URL` (адрес на Vercel) и `INDEXER_SECRET` (тот же, что на Vercel).

## Если что-то не так

- **Стили выглядят старыми** после правки `globals.css`: остановить сервер, удалить папку `.next` и запустить заново.
- **`Transaction version (1) is not supported`** в логе: код старше этой версии. Обнови его, удали `.next` и перезапусти.
- **`market cap unknown` / `[market] no market cap`** в логе: ни один источник цены не ответил. В строке лога видно, что случилось с каждым. Если DexScreener недоступен из твоей сети, это не страшно: пока монета на bonding curve, цену даёт сам блокчейн через Helius. После выхода монеты с pump.fun на проде (Vercel) DexScreener доступен.
- **Проект лежит в OneDrive** (например, на рабочем столе): исключите `node_modules` и `.next` из синхронизации или перенесите проект в папку вне OneDrive, иначе синхронизация будет гонять десятки тысяч файлов.

**Ограничение:** при проверке на сайте история кошелька читается до 1000 транзакций.
