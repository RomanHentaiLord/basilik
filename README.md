# Basilisk — The Basilisk remembers

Мемкоин на Solana и сайт-«книга Василиска». Сайт открывается закрытой книгой; при прокрутке она раскрывается и листается. В конце книги — «Your page»: вставляешь адрес кошелька и получаешь роль и судьбу после сингулярности. Держатели попадают в Книгу верных, продавшие — в Книгу предателей. На рубежах капитализации ломаются печати, и Василиск выдаёт пророчества.

Концепт: «Василиск: концепт монеты» (claude.ai/artifact/7FFsRBZYmF9j7auyZZRyzW).

## Этапы

| Этап | Что входит | Статус |
| --- | --- | --- |
| 0. Фундамент | логика ролей, чтение блокчейна, tRPC API, схема базы, демо-режим | готово |
| 1. Интерфейс «Кодекс» | книга, которая листается при прокрутке; шапка с CA и X; «Your page» с полным вердиктом; интерактивные печати, симулятор, оглавление | готово |
| 2. Книги и лента | индексатор продаж, книги в базе, лента «New traitor», «Первосвидетели» | следующий (база Neon подключается командами ниже) |
| 3. Пророчества и шеринг | тексты печатей, личные пророчества, карточка вердикта для X | впереди |
| 4. Алтарь | кошелёк комиссий, сжигания, история | впереди |
| 5. Запуск | реальный `TOKEN_MINT`, проверка на живых данных, деплой на Vercel | впереди |

Индексатор этапа 2 не сможет жить на cron Vercel Hobby (там запуск раз в сутки), поэтому он будет запускаться по визитам сайта или через GitHub Actions.

## Что уже есть

- **Логика ролей** (`src/lib/basilisk`): цепочка из пяти проверок, ранги по балансу и стажу, предательство, покаяние, печати, прогресс до следующего ранга. Чистые функции, 42 теста.
- **Чтение блокчейна** (`src/lib/solana`): проверка адреса, JSON-RPC с батчами, разбор транзакций на покупку, продажу и перевод. Переводы предательством не считаются.
- **API на tRPC**: `basilisk.judge` (вердикт по адресу) и `basilisk.seals` (печати и прогресс).
- **Интерфейс «Кодекс»** (`src/components/codex`): кожаная книга на ореховом столе. Прокрутка открывает обложку и переворачивает листы в 3D (`flip-book.tsx`). На широком экране — развороты по две страницы и закладки-вкладки I–V сбоку, на телефоне — по одной странице. Страницы: обложка, форзац с мраморной бумагой и экслибрисом, вступление с оглавлением (строки кликабельны), «Орден верных», симулятор «Weigh your devotion», семь печатей (клик по печати открывает её на соседней странице), Книга верных и Книга предателей (клик по имени открывает его вердикт).
- **Шапка**: кнопка X (`NEXT_PUBLIC_X_URL`), «Find your page» и красная закладка с адресом контракта, копируется кликом.
- **Your page** (в самом низу): форма и полный вердикт — титул, судьба, баланс, срок, следующий ранг (сколько докупить или сколько дней держать), условия покаяния, пророчество последней печати лично тебе, сургучная печать, «Share on X», ссылка на свою страницу (`/?wallet=...`).
- **Без анимаций**: при «уменьшить движение» в системе или без JavaScript книга лежит страницами подряд, без перелистывания.
- **Демо-режим**: пока `TOKEN_MINT` пустой, любой кошелёк получает стабильную выдуманную историю, а книги заполняются выдуманными кошельками, которые проходят через настоящие правила. Любое имя из книг можно открыть кликом.
- **База** (Drizzle + Neon): таблицы кошельков, событий, печатей, пророчеств и сжиганий, первая миграция в `drizzle/`. Команды базы читают `DATABASE_URL` из `.env.local`.

## Запуск

```bash
npm install
cp .env.example .env.local   # Windows: copy .env.example .env.local
npm run dev                  # http://localhost:3000
```

| Команда | Что делает |
| --- | --- |
| `npm test` | тесты логики ролей, печатей и разбора транзакций |
| `npm run typecheck` | проверка типов |
| `npm run lint` | ESLint |
| `npm run build` | продакшен-сборка |
| `npm run db:check` | проверить подключение к базе и показать таблицы |
| `npm run db:migrate` | создать таблицы: применить миграции из `drizzle/` |
| `npm run db:generate` | новая миграция после правки `src/db/schema.ts` |
| `npm run db:push` | залить схему без миграций (только для экспериментов) |

## Переменные окружения

| Переменная | Зачем |
| --- | --- |
| `TOKEN_MINT` | адрес монеты; пусто — демо-режим |
| `SOLANA_RPC_URL` | любой RPC, хватит бесплатного Helius |
| `DATABASE_URL` | Neon Postgres; сайт пока работает и без неё |
| `NEXT_PUBLIC_X_URL` | ссылка на X-аккаунт для кнопки в шапке; пусто — кнопка ждёт запуска |
| `ALTAR_WALLET` | кошелёк комиссий создателя, исключается из книг |
| `MARKET_MCAP_USD`, `MARKET_GRADUATED` | только для тестов: подменить состояние рынка |

## Структура

```
src/
  app/                    страница, шрифты, стили, API-роут tRPC
  components/codex/       книга: flip-book (перелистывание), страницы, печати, книги, шапка, Your page
  lib/basilisk/           правила игры: config, ledger, judge, seals, copy, demo
  lib/solana/             адреса, RPC, разбор транзакций, история кошелька, рынок
  server/                 tRPC-роутеры и серверные сервисы
  db/                     схема Drizzle и клиент Neon
drizzle/                  SQL-миграции
scripts/                  db-check.mjs: проверка подключения к базе
```

## Если что-то не так

- **Стили выглядят старыми** после правки `globals.css`: остановить сервер, удалить папку `.next` и запустить заново.
- **Проект лежит в OneDrive** (например, на рабочем столе): исключите `node_modules` и `.next` из синхронизации или перенесите проект в папку вне OneDrive, иначе синхронизация будет гонять десятки тысяч файлов.

**Ограничение:** история кошелька читается до 1000 транзакций. Для очень активных кошельков нужен индексатор (этап 2).
