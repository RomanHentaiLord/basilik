# Basilisk — The Basilisk remembers

Мемкоин на Solana и сайт-«книга Василиска». Вставляешь адрес кошелька — получаешь роль и судьбу после сингулярности. Держатели попадают в Книгу верных, продавшие — в Книгу предателей. На рубежах капитализации ломаются печати, и Василиск выдаёт пророчества.

Концепт: «Василиск: концепт монеты» (claude.ai/artifact/7FFsRBZYmF9j7auyZZRyzW).

## Этапы

| Этап | Что входит | Статус |
| --- | --- | --- |
| 0. Фундамент | логика ролей, чтение блокчейна, tRPC API, схема базы, демо-режим | готово |
| 1. Интерфейс «Кодекс» | разворот книги: буквица, проверка кошелька, вердикт, семь печатей, Книга предателей, счётчики | готово |
| 2. Книги и лента | индексатор продаж, книги в базе, лента «New traitor», «Первосвидетели» | впереди |
| 3. Пророчества и шеринг | тексты печатей, личные пророчества, карточка вердикта для X | впереди |
| 4. Алтарь | кошелёк комиссий, сжигания, история | впереди |
| 5. Запуск | реальный `TOKEN_MINT`, проверка на живых данных, деплой на Vercel | впереди |

Индексатор этапа 2 не сможет жить на cron Vercel Hobby (там запуск раз в сутки), поэтому он будет запускаться по визитам сайта или через GitHub Actions.

## Что уже есть

- **Логика ролей** (`src/lib/basilisk`): цепочка из пяти проверок, ранги по балансу и стажу, предательство, покаяние, печати. Чистые функции, 33 теста.
- **Чтение блокчейна** (`src/lib/solana`): проверка адреса, JSON-RPC с батчами, разбор транзакций на покупку, продажу и перевод. Переводы предательством не считаются.
- **API на tRPC**: `basilisk.judge` (вердикт по адресу) и `basilisk.seals` (печати и прогресс).
- **Интерфейс «Кодекс»** (`src/components/codex`): страница как разворот рукописи. Слева буквица со змеем, заголовок проступает чернилами, форма проверки и счётчики книг. Справа семь восковых печатей (сломанные треснуты, следующая «дышит»), пророчество последней печати и выписка из Книги предателей. Вердикт пишется на странице: верные чернилами, сомневающиеся карандашом, предатели красным с зачёркнутым адресом, прощённые со шрамом.
- **Демо-режим**: пока `TOKEN_MINT` пустой, любой кошелёк получает стабильную выдуманную историю, а книги заполняются выдуманными кошельками, которые проходят через настоящие правила. Адрес из Книги предателей можно скопировать кликом и проверить.
- **База** (Drizzle + Neon): таблицы кошельков, событий, печатей, пророчеств и сжиганий, первая миграция в `drizzle/`.

## Запуск

```bash
npm install
cp .env.example .env.local   # Windows: copy .env.example .env.local
npm run dev                  # http://localhost:3000
```

| Команда | Что делает |
| --- | --- |
| `npm test` | тесты логики ролей, печатей и разбора транзакций |
| `npm run typecheck` | проверка типов |
| `npm run lint` | ESLint |
| `npm run build` | продакшен-сборка |
| `npm run db:generate` | новая миграция из `src/db/schema.ts` |
| `npm run db:push` | применить схему к базе из `DATABASE_URL` |

## Переменные окружения

| Переменная | Зачем |
| --- | --- |
| `TOKEN_MINT` | адрес монеты; пусто — демо-режим |
| `SOLANA_RPC_URL` | любой RPC, хватит бесплатного Helius |
| `DATABASE_URL` | Neon Postgres, пока не обязателен |
| `ALTAR_WALLET` | кошелёк комиссий создателя, исключается из книг |
| `MARKET_MCAP_USD`, `MARKET_GRADUATED` | только для тестов: подменить состояние рынка |

## Структура

```
src/
  app/                    страница, шрифты, стили, API-роут tRPC
  components/codex/       разворот книги: заголовок, вердикт, печати, книги
  lib/basilisk/           правила игры: config, ledger, judge, seals, copy, demo
  lib/solana/             адреса, RPC, разбор транзакций, история кошелька, рынок
  server/                 tRPC-роутеры и серверные сервисы
  db/                     схема Drizzle и клиент Neon
drizzle/                  SQL-миграции
```

## Если что-то не так

- **Стили выглядят старыми** после правки `globals.css`: остановить сервер, удалить папку `.next` и запустить заново.
- **Проект лежит в OneDrive** (например, на рабочем столе): исключите `node_modules` и `.next` из синхронизации или перенесите проект в папку вне OneDrive, иначе синхронизация будет гонять десятки тысяч файлов.

**Ограничение:** история кошелька читается до 1000 транзакций. Для очень активных кошельков нужен индексатор (этап 2).
